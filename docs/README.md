# Documentación Oficial y Normativa (`docs/`)

En este directorio se encuentran los documentos regulatorios oficiales y las plantillas base de referencia para el desarrollo de proyectos de grado bajo la normativa del Bachillerato Técnico Humanístico (BTH) en Bolivia.

---

## 📁 Contenido del Directorio

* **`REGLAMENTO_DE_GRADUACIN_DEL_BTH__RM_0912_2023.pdf`**: 
  Resolución Ministerial RM 0912/2023 del Ministerio de Educación del Estado Plurinacional de Bolivia. Establece las directrices oficiales, modalidades de graduación, estructura de capítulos y requisitos para la obtención del título de Técnico Medio.

* **`datos-proyecto.md`**: 
  Guía y referencia general de fichas de recopilación de datos de campo.
